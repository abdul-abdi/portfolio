# Kinetic Narrative — Personal Portfolio

A modern, animated portfolio site for Abdullahi Abdi, Agent Engineer specializing in Context Engineering and AI Agent design.

## Tech Stack

- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS with custom design system
- **UI Components:** shadcn/ui (Radix UI primitives)
- **Animations:** Framer Motion
- **Smooth Scrolling:** Lenis

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
├── components/
│   ├── sections/      # Page sections (Hero, About, Works, etc.)
│   └── ui/            # shadcn/ui components
├── hooks/             # Custom React hooks
├── lib/               # Utilities
└── pages/             # Route pages
```

## Features

- Scroll-triggered animations
- Infinite skills ticker
